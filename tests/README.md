# Тесты проекта визуализаций

Здесь размещаются тесты вашего кода из `src`. Папка `tests` не входит в
webpack-сборку и не загружается на BI-сервер.

Команда `yarn test` по умолчанию использует `node:test`. При необходимости
замените её в `package.json` выбранным для проекта runner (например, Vitest или Jest с нужной обработкой TSX/React).
Для простого JavaScript можно использовать встроенный `node:test`:

```json
{
  "scripts": {
    "test": "node --test tests/*.test.js"
  }
}
```

Добавляйте эту команду вместе с реальными `tests/*.test.js`. Тесты могут
импортировать код из `../src/...`; настройка TypeScript, JSX, DOM и externals
зависит от выбранного runner и визуализации.

Проверки pull/build/dev-сервера находятся отдельно в `scripts/__tests__` и
запускаются отдельно командой `yarn test:scripts` (или вместе с остальными через `yarn test`). Они нужны при изменении
инфраструктуры; запускать их при разработке визуализаций не требуется.
